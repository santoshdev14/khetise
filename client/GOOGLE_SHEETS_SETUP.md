# 🥬 Google Sheets Product Database Setup Guide for Kheti Se

This guide explains how to manage your entire vegetable store (add items, update prices, change photos, reorder items, or mark items out of stock) directly from a Google Sheet without touching any code!

---

## 📋 Step 1: Create Your Google Sheet

1. Open [Google Sheets](https://sheets.new) and create a **Blank spreadsheet**.
2. Rename the spreadsheet to **“Kheti Se - Products”** (or any name you prefer).
3. In the **first row (Row 1)**, create the following **9 column headers** exactly as shown:

| Column A | Column B | Column C | Column D | Column E | Column F | Column G | Column H | Column I |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **id** | **name** | **price** | **unit** | **image** | **category** | **description** | **available** | **sort_order** |

---

## 📝 Column Explanations & Examples

| Column Header | What to write | Examples |
| :--- | :--- | :--- |
| **`id`** | Unique number or code for the vegetable | `1`, `2`, `tomato_desi`, `aloo_01` |
| **`name`** | Vegetable name (can include Hindi name in brackets) | `Tomato (देसी टमाटर)`, `Potato (आलू)`, `Spinach (पालक)` |
| **`price`** | Numerical price in ₹ | `40`, `30`, `50` |
| **`unit`** | Sale unit | `Kg`, `500g`, `250g`, `Bunch`, `Pc` |
| **`image`** | Direct image link (URL) | `https://images.unsplash.com/...` |
| **`category`** | Category name (Creates automatic website filters!) | `Daily Essentials`, `Leafy Greens`, `Salads & Herbs`, `Gourds` |
| **`description`** | Short customer description | `Fresh red ripe tomatoes picked this morning` |
| **`available`** | `TRUE` if available to buy, `FALSE` to mark Out of Stock | `TRUE` or `FALSE` |
| **`sort_order`** | Display position (1 = first item shown) | `1`, `2`, `3`, `4` |

## 🌐 Step 2: Publish Your Google Sheet to the Web

To allow the website to read your sheet in real time:

1. In your Google Sheet, click **File** (top menu).
2. Hover over **Share** and click **Publish to web**.
3. Under *Link*, change **Entire Document** (or *Sheet1*) to **Comma-separated values (.csv)**.
4. Click the blue **Publish** button.
5. **Copy the link** generated by Google Sheets.

It looks like this:
```text
https://docs.google.com/spreadsheets/d/e/2PACX-1vQ.../pub?output=csv
```

*(Alternative method: Click the top right **Share** button, change access from "Restricted" to **"Anyone with the link can view"**, and copy the Spreadsheet ID from the browser URL bar).*

---

## ⚙️ Step 3: Connect Google Sheet to the Website

Open the `.env` file (or `src/config/siteConfig.js`) in your project and paste your link:

### Option A: In `.env` file (Recommended)
```env
VITE_GOOGLE_SHEET_CSV_URL=https://docs.google.com/spreadsheets/d/e/YOUR_PUBLISHED_LINK/pub?output=csv
VITE_WHATSAPP_NUMBER=919876543210
```

### Option B: In `src/config/siteConfig.js`
```javascript
googleSheets: {
  csvUrl: "https://docs.google.com/spreadsheets/d/e/YOUR_PUBLISHED_LINK/pub?output=csv",
  sheetId: "",
  sheetName: "Sheet1"
}
```

## 🎯 How to Manage Your Store Daily

### 💰 1. How to Change a Price
- Simply click on the price cell in Google Sheets and type the new number (e.g., change `40` to `50`).
- The website, cart, and WhatsApp message will immediately use ₹50.

### 📸 2. How to Change or Add Vegetable Photos
- Paste any image link into the `image` column.
- Free image sources: [Unsplash](https://unsplash.com), [Imgur](https://imgur.com), or your own hosted pictures.
- If an image link ever breaks, the website automatically displays a clean farm-fresh fallback photo without breaking the page.

### ➕ 3. How to Add a New Vegetable
- Simply add a new row at the bottom with a new ID, Name, Price, Unit, Photo link, and Category.
- It will instantly appear on the website!

### 🛑 4. How to Temporarily Stop Selling an Item (Out of Stock)
- Change the `available` column for that row to `FALSE`.
- The product card will automatically show an **"Out of Stock"** badge and disable the Add button.
- When it's back in stock, change it back to `TRUE`.

### 🔢 5. How to Reorder Vegetables on the Homepage
- Adjust the number in the `sort_order` column (e.g. set `1` for the most popular item you want at the top).

## 🔍 Step 4: How to Test Live Updates

1. Start your store:
   ```bash
   npm run dev
   ```
2. Open `http://localhost:5173/` in your browser.
3. In your Google Sheet, change Tomato price from `40` to `55`.
4. On the website, click the small **Refresh 🔄** icon next to *“Today's Harvest”* or reload the page.
5. Notice that Tomato now shows **₹55 / Kg**, and adding it to the cart computes `₹55` automatically!
